# Privacy Policy for Regen Network Assistant

**Effective Date:** January 2, 2026
**Last Updated:** January 2, 2026

## Overview

The Regen Network Assistant ("Assistant") is a Custom GPT that provides information about Regen Network's ecological credit ecosystem. This policy describes how we handle data when you use the Assistant.

## What We Collect

### Conversation Data
- Your questions and the Assistant's responses are processed by OpenAI per their [Privacy Policy](https://openai.com/policies/privacy-policy)
- We do not store conversation logs on our servers

### API Queries
- When the Assistant queries our APIs on your behalf, we log:
  - Request timestamps
  - Endpoint accessed
  - Response status codes
- We do NOT log:
  - Your identity or OpenAI user ID
  - Query content or parameters
  - IP addresses

### On-Chain Data
- Blockchain queries return public ledger data
- No personal information is collected through ledger queries

## How We Use Data

- API logs are used solely for:
  - Service monitoring and uptime
  - Error debugging
  - Usage analytics (aggregate, anonymized)

## Data Retention

- API logs are retained for 30 days
- No personal data is retained

## Third Parties

- **OpenAI**: Processes all conversations per their policies
- **Regen Network**: Public blockchain data is queried from the Regen ledger

## Changes

We may update this policy. Material changes will be noted in the "Last Updated" date.
